# RentDirect Flutter App

This folder contains the Flutter mobile app implementation scaffold (Riverpod + GoRouter + Material 3).

## Local setup

1. Install Flutter SDK.
2. From this folder, run:
   - `flutter create .`
   - `flutter pub get`
   - `flutter run`

## API endpoint

Configure the app to call Laravel API:

- Base URL: `http://127.0.0.1:8000/api/v1`
