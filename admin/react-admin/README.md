# RentDirect Admin Panel

React + TypeScript + Vite admin panel using:

- React Router
- TanStack Query
- React Hook Form + Zod
- react-i18next

## Setup

1. Copy `.env.example` to `.env`.
2. Set `VITE_API_BASE_URL` (default `http://127.0.0.1:8000/api/v1`).
3. Install dependencies:
   - `npm install`
4. Run in development:
   - `npm run dev`
5. Build production bundle:
   - `npm run build`
