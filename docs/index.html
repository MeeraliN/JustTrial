RentDirect Marketplace

A concept preview for the planned owner-to-tenant rental platform. This page is hosted from the repository to show a live output link while full Flutter, React and Laravel implementation is in progress.

Platform Stack

Flutter + Riverpod + GoRouter mobile app, React + TypeScript admin panel, Laravel + MySQL backend API.

Android + iOSMobile app
Role-basedAdmin panel
REST APISingle backend

Revenue Model

No rental commission. Monetization through ads, featured listings and business promotions.

Sponsored content will be clearly labeled.

Listings

House, flat, room, PG, hostel, shop and office listing flow with moderation states.

Search & Maps

Filter-based search, locality discovery, server-side pagination and map-assisted results.

Chat & Requests

In-app chat, image sharing, read status, reporting and viewing request workflows.

Localization

English and Hindi first, extensible language management through database content.
